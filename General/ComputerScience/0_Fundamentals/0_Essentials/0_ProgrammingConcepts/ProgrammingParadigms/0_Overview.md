# **Programming Paradigms Overview**

## 1. **Procedural Programming**
- **Key Concept**: Procedural programming is a subset of imperative programming, where programs are structured using procedures (functions) to organize and execute instructions sequentially.
Imperative programming, in contrast, is a broader paradigm that focuses on how a program achieves a result by specifying a sequence of commands. 
- **Approach**: Executes instructions sequentially, using loops and conditional statements.  
- **Advantages**:  
  - Easy to understand and follow.  
  - Suitable for small programs or simple tasks.  
- **Disadvantages**:  
  - Difficult to maintain and scale for large programs.  
  - Limited support for code reuse.  


## 2. **Object-Oriented Programming (OOP)**
- **Key Concept**: Organizes code around objects, which represent real-world entities with data (attributes) and behavior (methods).  
- **Approach**: Utilizes concepts like classes, inheritance, polymorphism, and encapsulation.  
- **Advantages**:  
  - Easier to maintain and extend due to a clear structure.  
  - Supports code reuse through inheritance and polymorphism.  
- **Disadvantages**:  
  - Can be complex and challenging for beginners.  
  - May lead to performance overhead due to the complexity of object management.  


## 3. **Declarative Programming**
- **Key Concept**: Focuses on **what** needs to be done rather than **how** to do it.  
- **Approach**: Uses expressions or statements to declare the desired outcome without specifying the control flow.  
- **Example**: SQL query, where you specify the data you want without defining how to retrieve it.  
- **Advantages**:  
  - Reduces errors by avoiding explicit state management.  
  - Leads to more concise and readable code.  
- **Disadvantages**:  
  - Limited control over the execution process.  
  - Not suitable for all types of problems.  


## 4. **Imperative Programming**
- **Key Concept**: Focuses on **how** to perform tasks by explicitly defining the steps to change the program's state.  
- **Approach**: Uses sequential commands, loops, and conditional statements to control the program flow.  
- **Advantages**:  
  - Provides full control over program execution.  
  - Suitable for tasks that require detailed state management.  
- **Disadvantages**:  
  - Can lead to complex and hard-to-maintain code.  
  - Error-prone when managing state and execution flow manually.  


### ✅ **Quick Summary**:

| Paradigm            | Focus                 | Example Languages        |
|-----------------|----------------|-----------------------|
| Procedural        | Step-by-step execution | C, Pascal |
| Object-Oriented | Objects and classes | Java, Python, C++ |
| Declarative       | What to do | SQL, HTML, Prolog |
| Imperative          | How to do | C, Python, JavaScript |
