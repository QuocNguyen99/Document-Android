# Repository Design Pattern

**Note:**

In MVC, MVVM, MVP models, Repository is not listed as a layer because it is not part of the model architecture, but a design pattern. The Repository pattern is used to address data access and management issues in applications and is often used in conjunction with other architectural models such as MVC, MVVM, MVP. The Repository pattern plays an important role in managing data access and processing, making it easier to separate components in the application.
