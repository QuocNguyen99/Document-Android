# Floating Point Types

We often use real numbers to perform calculations in science, statistics, engineering, and other fields. Kotlin has two basic types to represent real numbers: `Float` and `Double`. They are called floating-point types.


In fact, these types cannot represent an arbitrary real number because they support only a limited number of significant decimal digits (6-7 for `Float` and 14-16 for `Double`)

**In practice, programmers mostly use the Double type**. We will discuss this type, and we do recommend using it to solve our code challenges.
