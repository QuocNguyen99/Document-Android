# 4. **Declarative Programming**
- **Key Concept**: Focuses on **what** needs to be done rather than **how** to do it.  
- **Approach**: Uses expressions or statements to declare the desired outcome without specifying the control flow.  
- **Example**: SQL query, where you specify the data you want without defining how to retrieve it.  
- **Advantages**:  
  - Reduces errors by avoiding explicit state management.  
  - Leads to more concise and readable code.  
- **Disadvantages**:  
  - Limited control over the execution process.  
  - Not suitable for all types of problems.
