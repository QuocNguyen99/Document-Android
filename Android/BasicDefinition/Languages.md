# Android Programming Languages


Tất cả ứng dụng Android phải được viết bằng Kotlin, Java và/hoặc C/C++.
Kotlin và Java là ngôn ngữ chính mà các nhà phát triển sử dụng để xây dựng ứng dụng Android,
trong khi C++ được dùng để viết các tính năng hướng đến hiệu suất hoặc dựa trên phần cứng sử dụng
Java Native interface (JNI) để gọi các hàm gốc.

## Java

Khi Google tiết lộ phiên bản đầu tiên của hệ điều hành Android hơn một thập kỷ trước, 
họ đã sử dụng Java làm ngôn ngữ chính để phát triển ứng dụng Android.

Nhưng tại sao lại là Java? Là một trong những ngôn ngữ hướng đối tượng lâu đời nhất,
Java rất dễ học và hoạt động tốt trên máy ảo Dalvik, được lấy cảm hứng từ Máy ảo Java (JVM),
giúp nó có thể di chuyển được trên hầu hết mọi thiết bị và hệ điều hành. 
Vì vậy, khi Google bắt đầu xây dựng hệ thống Android, Java là một trong những ngôn ngữ phù hợp nhất.

## Kotlin

Kotlin được sinh ra từ JetBrains. Ban đầu nó được thiết kế cho môi trường JVM và kết hợp lập trình chức năng và hướng đối tượng.
Kể từ khi phát hành, Kotlin đã trở thành ngôi sao đang lên trong lĩnh vực phát triển Android và các lĩnh vực khác.

Dưới đây là một số lý do khiến Kotlin kết hợp rất tốt với Android:

Khả năng tương tác: Kotlin có khả năng tương tác 100% với Java và hỗ trợ khả năng tương tác tuyệt vời với môi trường JVM.
An toàn: Theo tài liệu Android, các ứng dụng Android chứa mã Kotlin có ít khả năng gặp sự cố hơn 20%.
Tính bất đồng bộ: Việc sử dụng coroutine của Kotlin cho phép nó cung cấp hỗ trợ lập trình bất đồng bộ (non-blocking).
Ngoài những điểm trên, Google đã công bố phương pháp tiếp cận Kotlin đầu tiên của họ để phát triển Android tại Google I/O 2019. 
Kể từ thông báo này, số lượng ứng dụng được xây dựng bằng Kotlin đã tăng theo cấp số nhân.
